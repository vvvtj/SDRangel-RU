# Проверка кириллицы и размеров надписей

Текущее состояние: каталог проверен локально, русский SDRangel не собран. Проверка реального отображения и отсутствие обрезания **не подтверждены**. Начальный каталог содержит 576 записей в восьми контекстах; это не показатель полного покрытия интерфейса.

После сборки с Qt Translator и установки `sdrangel_ru.qm`:

1. Выбрать Русский, выполнить обычный перезапуск. Убедиться, что активный язык в отчёте действительно `ru`.
2. При масштабе Windows 100%, 125% и 150% открыть главное меню, настройки, конфигурации, панель PlutoSDR и PlutoSDR MIMO. Проверить буквы Ё/ё, Ж/ж, Щ/щ, Й/й: без квадратов, знаков замены и искажённой кодировки.
3. Проверить длинные подписи, кнопки, списки, заголовки и подсказки. Посмотреть минимальный размер окон и обычное размещение управления слева, спектра/водопада справа. В MIMO проверить выбор RX0/RX1; TX оставлять остановленным.
4. В меню «Язык / Language» нажать «Проверить надписи / Check labels» для каждой группы открытых окон. Сохранить отчёты отдельно для каждого масштаба. Отчёт записывается в текущий рабочий каталог.
5. Проверить строки с `missingCyrillicGlyphs` и `potentialClipping=true`. `manualReviewRequired=true` требует осмотра; отсутствие флага обрезания для такой строки не означает успех. Меню, подсказки, скрытые окна и рисунки спектра также требуют визуального осмотра.
6. Выбрать English, перезапустить и проверить обратное переключение. Не запускать TX для проверки языка.

При обрезании менять только GUI-компоновку: минимальную ширину, перенос текста, отступы или формулировку перевода. Не переименовывать технические ключи, objectName, URI и сериализованные настройки. QFontMetrics даёт предварительную оценку; окончательный результат требует осмотра работающего Qt GUI.
