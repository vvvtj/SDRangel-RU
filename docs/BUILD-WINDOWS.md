# Сборка Windows x64

## База

Цель интеграции — SDRangel **v7.27.2**. Следует проверять зависимости по upstream Windows CI именно для используемого коммита, а не полагаться на устаревшие инструкции.

В оригинальном Windows workflow этой версии используются Visual Studio 2022 / MSVC, Qt 6.9.3, Boost 1.73.0, CMake, Ninja, NSIS и дополнительные модули Qt. Полный перечень нужно брать из [upstream workflow](https://github.com/f4exb/sdrangel/blob/master/.github/workflows/windows.yml) с учётом фиксированного тега.

## Процесс

1. Получить **точный** исходник SDRangel 7.27.2.
2. Извлечь сообщения Qt через `lupdate` из реальных контекстов.
3. Слить и проверить переводы, не нарушая placeholders (`%1`, `%2`), множественные формы и HTML-разметку.
4. Собрать `.qm` через `lrelease`.
5. Интегрировать `QTranslator` при запуске GUI; проверить выбор языка и перезапуск.
6. Собрать и протестировать приложение в Windows x64 CI.
7. При успешном тесте приложить артефакт и SHA-256; только после ручной проверки объявлять стабильный релиз.

## Текущие ограничения

Предварительные 576 строк каталога и локальные скрипты сами по себе **не доказывают**, что `lupdate` извлёк нужные контексты или готовая программа переведена. До переноса реальных исходников и первой CI-сборки артефакты отсутствуют.
