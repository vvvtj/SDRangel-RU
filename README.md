# SDRangel-RU — Russian Localization for Windows x64

**Основная платформа: Windows 10/11 x64.** Русификация SDRangel с Qt-переводами, Windows-сборками и проверкой совместимости SDR-устройств. Статус: в разработке; готовая русская сборка пока не подтверждена.

[Инструкция для Windows](docs/QUICKSTART.md) · [Сборка Windows x64](docs/BUILD-WINDOWS.md) · [Проверка релиза](docs/RELEASE-CHECKLIST.md)
