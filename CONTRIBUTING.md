# Как помочь русификации

- Сверяйте Qt context и source string перед изменением перевода.
- Сохраняйте placeholders `%1`, `%2`, пробелы, переносы, rich-text и множественные формы.
- Проверяйте длинные слова в маленьких кнопках и настройках.
- Для каждого изменения прикладывайте исходный текст, перевод, окно и скриншот.
- Не добавляйте к проекту бинарники чужих компонентов без проверки лицензии.
- Функции управления радио и DSP не должны меняться вследствие локализации.
